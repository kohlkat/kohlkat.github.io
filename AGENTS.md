# Public SAGE product-site contract

This repository is a public disclosure surface.

## Product framing

- Lead with the manufacturer problem, the reviewable SAGE deliverable, the
  workflow, and a concrete pilot path.
- Write for a first-time reader. Define technical terms and move deep evidence
  detail to the evidence or research routes.
- Present SAGE Suite as one product. Do not expose local operator-environment
  architecture as a separate customer product.

## Disclosure boundary

- Publish only reviewed, aggregate, rights-cleared, nonproprietary artifacts
  already copied into this repository.
- Never include private source, local paths, account metadata, credentials,
  customer or machine records, raw geometry or G-code, model weights,
  hyperparameters, objective weights, calibration/trust internals, proprietary
  routing or assurance logic, legal files, patent drafts, or enabling detail.
- Never call `SIMULATED` evidence physical validation or
  `modeled_not_measured` output a measurement.
- Never promise guaranteed machining improvement, certification, production
  safety, or autonomous machine authority.
- Keep negative technical findings in the evidence record even when the
  homepage remains product-first.

## Release gate

- Keep crawler, archive, security, privacy, consent, and provenance controls.
- Treat every checked-in media hash and manifest as an immutable public record.
  A visual replacement gets new versioned filenames, a new manifest, matching
  hashes, and a public evidence record; never overwrite a reviewed artifact.
- Never run a fallback or WebGL generator against an Isaac-bound replay asset.
  Do not claim contact, provenance, runtime, or physical status unless its
  reviewed runtime artifact records it.
- Third-party visual assets require a rights-cleared local copy, source URL,
  license, credit, and declared modification. CC BY credit must be visible on
  the route using the asset. Never hotlink a release asset.
- GPU/provider work stays outside this repository. Before any paid run: fresh
  scoped credential, current-source hash bundle, bounded price plan, watchdog,
  hard deadline, and provider-confirmed teardown. Never reuse stale captures
  or copy credentials into source, logs, Git, or public artifacts.
- Keep `SIMULATED` visible. Keep unavailable measurements null or `NaN`.
  Physical gate stays closed and learned outputs remain non-actuating.
- Run `npm run verify` before deployment.
- Review the production build locally at desktop and mobile widths before a
  visual-media release; preserve failed checks and fix root cause.
- Deploy the exact validated preview and then promote that exact deployment.
- Do not commit, push, connect a repository, or change domains without the
  owner's authorization.
