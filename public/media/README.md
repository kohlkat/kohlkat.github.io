# Public Simulation Media

`sage-simulation-replay-v3.mp4` is silent, non-headless NVIDIA Isaac Sim
6.0.1 footage rendered with Ray Traced Lighting. It alternates three public
geometry classes across two separate simulated paths:

- CNC surrogate-training scenes; and
- NVIDIA UR10e robot shadow-optimization scenes.

The scenes were generated specifically for public demonstration. They contain
no private campaign USD, customer geometry, machine program, controller path,
model weight, production sidecar, credential, or physical-machine recording.
Every frame remains `SIMULATED`; the independent physical gate remains closed.

`sage-isaac-capture-manifest-v3.json` is the immutable renderer output manifest.
`sage-simulation-replay-manifest-v3.json` binds the web assets to that capture.
