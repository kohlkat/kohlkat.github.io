# Public Simulation Media

`sage-simulation-replay-v1.mp4` is a silent screen capture of SAGE's reviewed,
public-safe browser simulation replay. It uses generic procedural geometry and
source-synchronized simulated telemetry.

It is not an NVIDIA Isaac Sim or Omniverse capture, a customer cell, measured
machine footage, or one of the three shadow-learning result cases shown on the
product page.
